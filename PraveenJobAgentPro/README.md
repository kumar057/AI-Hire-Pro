# Praveen Job Agent Pro

A Windows-first local job search assistant built around Praveen Kumar's AI Engineer fresher profile.

## Included
- Public Greenhouse and Lever job discovery
- Resume/profile matching score
- SQLite tracking
- Shortlist and applied statuses
- Local dashboard
- Windows launcher
- LinkedIn and Naukri excluded

## Run
Double-click `run.bat`, then open http://127.0.0.1:8000.

Add official Greenhouse board tokens or Lever site names to `config/sources.json` before scanning.

## Safety
Never store passwords, OTPs, browser cookies or session tokens. Do not bypass CAPTCHA, MFA, assessments, anti-bot controls, or required declarations. Browser-assisted application filling can be added after the local dashboard is verified.
